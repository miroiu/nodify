Pure MVVM Architecture & Core Control Flow

Nodify is built from the ground up to respect MVVM separation. Nodes, connections, pins, and selection states are completely decoupled from UI rendering logic, driven via ItemsSource, Connections, and custom command gestures.

  • ✓
    NodifyEditor Canvas: Main virtualized viewport container managing zoom, spatial pan, auto-scroll bounds, and marquee box selection.
  • ✓
    ItemContainer & BaseNode: Item container wrapper hosting header, input pins, output pins, and custom user data templates.
  • ✓
    PendingConnection & Spline Circuit: High-performance line rendering supporting Bezier curves, circuit lines, cutting line gestures, and pin snapping.
  • ✓
    NodifyMinimap: Integrated navigation thumbnail reflecting complete viewport layout with drag-to-navigate capabilities.

XAML Integration Example

<xmlns:nodify="clr-namespace:Nodify;assembly=Nodify">

<nodify:NodifyEditor ItemsSource="{Binding Nodes}"
                     Connections="{Binding Connections}"
                     PendingConnection="{Binding PendingConnection}"
                     ViewportZoom="{Binding ZoomLevel}"
                     ViewportLocation="{Binding Location}">
    <nodify:NodifyEditor.ItemTemplate>
        <DataTemplate>
            <nodify:Node Header="{Binding Title}"
                         Input="{Binding Inputs}"
                         Output="{Binding Outputs}" />
        </DataTemplate>
    </nodify:NodifyEditor.ItemTemplate>
</nodify:NodifyEditor>
